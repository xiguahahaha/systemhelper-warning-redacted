# 已上传画像数据的删除请求指南

> 这不是法律意见。具体权利行使请以《个人信息保护法》及官方渠道答复为准。

## 1. 先理解两件事

1. **手机本地删除 ≠ 服务器删除**。`pm clear` / 卸载只能清掉本地缓存和待重试队列。
2. **服务器端没有“一键删除”按钮**。需要向数据控制者（某运营商）提交“撤回同意 + 查阅/复制 + 删除”请求，并保留工单证据。

## 2. 可用的渠道

| 渠道 | 说明 |
|---|---|
| 运营商客服 | 说明是“个人信息删除/撤回同意”诉求，要求转数据保护/隐私专员，不要只当普通投诉 |
| 运营商官方 APP 在线客服 | 同上，保存聊天记录/工单号 |
| 当地营业厅 | 运营商隐私政策明确写明可前往营业厅提出删除请求，带身份证 |
| 隐私政策联系方式 | 以运营商官网最新隐私政策为准（本仓库不公开具体邮箱/电话） |
| 工信部电信用户申诉 `12381` | 运营商拒绝/逾期后的升级渠道 |
| 网信办举报 `12377` | 违规收集个人信息 |
| `12315` | 消费者权益渠道 |

## 3. 提交前准备

- 手机号、设备 IMEI（双卡都记）、机型
- 应用包名/版本：`com.mobiletools.systemhelper` / `3.0.1-20251209`
- APK SHA-256（可选项，证明你指的是哪个样本）
- 服务器：运营商 DM 域名（本仓库已脱敏；真实值可从抓包/设备配置获取）
- 上传时间范围（大概即可）
- 是否为该运营商用户、是否使用该运营商定制机
- 设备是否 root、是否已卸载（说明未来采集已停止）

   数据来源、保存期限）及数据接收方/共享方清单；
3. 删除与本人手机号/设备 IMEI 关联的全部终端注册、位置轨迹、

## 5. 法律依据（《个人信息保护法》）

| 条款 | 内容要点 |
|---|---|
| 第 15 条 | 个人有权撤回同意；撤回同意后，个人信息处理者应当停止处理 |
| 第 44 条 | 个人对其个人信息的处理享有知情权、决定权，有权限制或拒绝处理 |
| 第 45 条 | 有权查阅、复制；符合条件时可请求转移 |
| 第 47 条 | 处理目的已实现/无法实现、停止提供服务、同意撤回等情形下，应当删除 |
| 第 48 条 | 有权要求解释说明处理规则 |
| 第 50 条 | 应当建立便捷的个人行使权利的申请受理和处理机制 |

## 6. 对方可能的答复与应对

| 答复 | 应对 |
|---|---|
| “用于网络优化/服务改进，已在隐私政策告知” | 服务改进不是法定必须留存；本人已撤回同意，依据第 15/47 条应停止并删除 |
| “数据已匿名化/聚合，不再是个人信息” | 要求证明不可复原；按 IMEI/手机号关联的数据仍属个人信息 |
| “属于法定留存，不能删除” | 要求书面列明法律依据、条款、保存期限；区分计费/网络日志与位置/应用画像 |
| “请走营业厅” | 按要求去营业厅，带身份证，保留回执；同时提交运营商工单 |
| “查不到这个应用/不是我们的” | 提供包名、证书 Subject、服务器地址、`pm path`、上传时间；要求转安全/数据保护团队 |
| 逾期不答复 | 12381 申诉；12377 举报；12315 投诉 |

## 7. 现实预期

- **计费记录、网络日志**：可能因《网络安全法》第 21 条（日志至少留存 6 个月）等规定被保留；这部分通常无法删除。
- **位置轨迹、应用使用画像**：不属于法定必须留存，应当可以删除。
- **已聚合/匿名化的统计**：对方可能拒绝删除，但你可以要求其说明聚合方式并证明不可复原。
- **第三方（百度）**：百度定位 SDK 可能独立向百度服务器发送定位/设备数据。让运营商披露接收方，并向百度隐私渠道单独提出删除请求。
- **合约机**：终端注册数据可能与补贴/激活/白名单绑定；删除前确认不影响合约，但这不构成拒绝删除画像数据的理由。

## 8. 证据保留

- 工单号、客服通话录音/聊天截图
- 提交时间、对方答复时间
- 你提供的 IMEI/手机号
- 应用包名、版本、`pm path` 截图
- 如需抓包：PCAPdroid 截图（显示发往运营商 DM 域名的 POST）
- 不要伪造证据；不要对服务器做未授权测试
